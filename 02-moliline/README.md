# 02 · MoliLine（模力线）— 程序间消息总线

让同一台电脑上的程序互发消息：请求/应答、事件广播、命令执行。带日志、
去重、死信、重连、多节点选主等可靠行为。无第三方依赖，用 Windows 自带
C# 编译器构建。

## 一、基础能力（本仓库可直接运行）

1. 注册与路由
   - 服务方启动时注册自己的名字和主题；
   - 控制方按名字发请求，按主题发事件广播。
2. 消息类型
   - REGISTER：服务方注册；
   - SEND / REPLY：一问一答（请求 → 执行 → 返回结果）；
   - PUBLISH / EVT：事件广播，同一主题的订阅者都能收到；
   - CMD / RESP：总线把命令投递给服务方，服务方回报执行结果。
3. 通用执行命令（内置 world_svc_tcp 可直接测）
   - PING / ECHO / STATUS / STATS / SLEEP / FAIL_ONCE / WRITE。
4. 事件驱动空闲：连接保持、有消息才触发（不忙轮询）。

## 二、可靠性能力（本仓库可直接运行）

- WAL 日志：命令先写盘再路由，程序重启后补发未完成请求；
- exactly-once：同一请求只执行一次（服务方持久化去重表）；
- 死信：目标不在线时请求写入死信记录并返回不可达；
- 重试：服务方可返回“请重试”，总线重发一次；
- 自动重连 + 总线地址轮换：断线后自动换下一个地址重连；
- 重启恢复：崩溃后重启，恢复服务并补发（测试矩阵覆盖）。

## 三、多节点能力（本仓库可直接运行）

- 心跳握手：节点间互相报告存活；
- 自动选主：存活节点中端口最小的当主节点；
- 主节点故障交接：三节点下约 6 秒内选出新主，执行者自动迁移并恢复；
- 防脑裂：少数派节点停止服务（两节点为严格多数派 2/2，一个下线即停服）。

规模选择：1 节点开箱即用；2 节点需同时在线；3 节点及以上可故障转移。

## 四、性能相关（历史实验记录，复现脚本未全部随仓库打包）

- 本机当前自测：单节点请求应答为毫秒级（见 run_matrix_refactor.py）；
- 历史实验记录（旧实现，仅供参考，引用前请按当前代码复跑）：
  - 链路延迟约 0.02–0.1 ms 级；
  - 吞吐约 4.5 万条/秒（单 TCP），8 并联线约 17.8 万条/秒，
    64 并联线约 24.7 万条/秒；
  - 副本并联加速：3 份约 3 倍、16 份约 16 倍；
  - 事件驱动空转能耗远低于轮询（CPU 时间代理实测）。

## 五、跨语言与承载（部分历史实验记录）

- 协议为 UTF-8 行协议，payload 用 base64，语言无关；
- 历史实验验证过 C# 与 Python 互发消息的闭环；
- 历史实验验证过多种承载方式（文件/事件/TCP/HTTP）与一个网页版
  “世界浏览器”原型；
- 本仓库当前直接提供 TCP 承载实现与协议文档（docs/WIRE.md）。

## 六、程序世界扩展能力（当前示例 + 历史实验记录）

- 折叠世界互联（历史实验记录）：总线可驱动 .fs 折叠世界——校验、
  启动、并联运行（对有道/QQ/抖音等真实目录做过无损折叠与运行验证）；
- 模型世界（本仓库 examples/model-world 可直接跑）：
  - 把 GGUF 折成 .fs“世界文件”；
  - 经总线 ON/OFF 启动/停止其中的模型；
  - 一个运行中的模型可以“进入”另一个世界（不启动对方）、读写其文件、
    回到自己的世界；
  - SAVE 把运行期修改保存回 .fs；
  - 代理模式：模型拿受限工具集自主操作世界内程序（读文件→改配置→运行）。
- 程序间“知识/数据”传输（历史实验记录）：A 程序把词典/词条导出，
  B 程序订阅后立即可查询，属于真转移而非仅转发；
- 输入影响黑盒程序（历史实验记录，工具在作者侧）：向标准文本控件注入
  文本并读回（记事本实测）；游戏类输入受输入架构与反作弊限制，不保证；
- 视觉定位→点击（历史实验记录）：根据画面中颜色块定位真实坐标并点击。

## 七、限制与说明

- 无登录与加密：仅本机/内网；
- 两节点无故障转移（2/2 多数派防脑裂设计）；
- 历史实验数字与代码为旧实现，公开引用前建议按当前实现复跑；
- 总线可让程序 A 控制程序 B：请在受控、可审计环境使用。

## 八、构建与测试

```bash
powershell -File build.ps1
python examples/hello.py
python run_matrix_refactor.py      # 单节点：PING/ECHO/STATS/死信/恢复
python run_multinode_refactor.py   # 多节点：选主/故障转移/防脑裂
```

手动：

```text
bin\moli_line_refactor.exe --port 47001 --workdir <dir>
bin\world_svc_tcp.exe     executor events 127.0.0.1:47001
bin\world_ctl_tcp.exe     47001 SEND executor PING
```

参数：总线 `--port/--workdir/--peer`；服务方 `<名字> <主题> [地址...]`，
去重目录可用环境变量 MOLI_DONE_DIR 指定（见 src/world_svc_tcp.cs）。
